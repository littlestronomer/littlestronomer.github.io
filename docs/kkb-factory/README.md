# KKB project page: factory mockup

A throwaway mockup for the project page about the KKB Hackathon: Agentic Data Analytics, where
Uçan Hamsiler (Ahmet Selim Özel, Alihan Esen and me) took 1st place. Open `mockup.html` in a
browser and scroll inside the window. The site's build does not use this folder.

## The idea so far

- The project gets a page of its own, laid out like the portfolio's main page: a pixel masthead,
  tabs, an introduction note with highlights, boxes down the side, and notes down the page.
- Behind the notes, where the main page has its night sky, there is a Factorio factory seen from
  above. The notes scroll up as usual and the factory slides sideways, the way the walk does, so
  scrolling travels along it from left to right.
- The words give the competition's aim and what we built. The draft copy in the mockup comes from
  the hackathon repo's README.md and FEATURES.md and from Coderspace's announcement.
- The factory is the project. Ore fields are the EVDS and BDDK data, and furnaces are the
  lakehouse (bronze, silver, gold). One big assembler is build_table. After it, a pair of machines
  for each tool stands along one belt: deflate, index, python (walled in, for the sandbox), plot,
  lead and lag, answer and lab. A rocket silo at the end launches when the page reaches its bottom.
- Inserters really move the items, and each machine turns what it gets into the next item. Two
  trains bring documents straight into the answer machines.
- Feedback that shaped it: it should look like a working factory, with arms operating and items
  changing along the way, and it should be tidy. Every machine stands on the line, on one concrete
  floor, on a grid of 6-pixel tiles.
